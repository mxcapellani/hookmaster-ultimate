# Instalação e atualização

Clonar `https://github.com/mxcapellani/hookmaster-ultimate.git` ou baixar os arquivos. Copiar `.agents/skills/hookmaster-ultimate/` para o local de descoberta aceito pelo seu agente. Ativar pelo nome quando a plataforma permitir e testar “Crie cinco hooks sobre produtividade”. Importação depende do host; publicar no GitHub não instala a Skill automaticamente.

A biblioteca externa PBL não é necessária. Python e PyYAML são dependências de validação do repositório, não da geração textual. Serviços e geração de mídia não são necessários.

Para atualizar, preservar personalizações separadamente, substituir a pasta por versão validada, consultar changelog e repetir os casos comportamentais já aprovados. Não atribuir memória persistente à Skill.
