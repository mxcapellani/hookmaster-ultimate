# Extração estrutural e referências

1. Conferir acesso real ao texto, documento, mídia ou transcrição.
2. Registrar exatamente o que está disponível: uma transcrição não comprova expressão facial ou edição.
3. Identificar assunto, público, promessa, elemento de contraste e lacuna informativa.
4. Abstrair a estrutura sem copiar frases extensas.
5. Aplicar ao novo tema com dados reais fornecidos.
6. Conferir consistência com o roteiro e direitos do material.

A biblioteca PBL citada na fonte não acompanha este pacote. Não alegar mil exemplos disponíveis. Para análise de imagem, visão é condicional; para vídeo, usar mídia ou transcrição realmente acessível. Se só houver link bloqueado, pedir conteúdo alternativo.

Organizar biblioteca por ID, assunto, público, objetivo, estilo, estrutura, texto original produzido e origem. Retenção e status de publicação só entram com dados reais. Não confundir organizador textual com arquivo persistido automaticamente.
